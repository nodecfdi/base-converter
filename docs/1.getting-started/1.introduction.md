`@nodecfdi/base-converter` es una librería escrita en TypeScript diseñada para convertir cadenas numéricas entre bases arbitrarias (desde base 2 en adelante) sin sufrir las limitaciones de precisión de los tipos numéricos nativos de JavaScript (`Number.parseInt` o `Number.parseFloat`).

## ¿Por qué usar Base Converter?

En JavaScript estándar, `Number.parseInt(valor, base)` pierde precisión cuando el número supera `Number.MAX_SAFE_INTEGER` ($2^{53} - 1$) o utiliza notación científica a partir de $10^{21}$. Esto representa un problema crítico cuando se procesan números de serie de certificados digitales (como los CSD o e.firma del SAT de 20 dígitos hexadecimales / 40 caracteres) u otros identificadores criptográficos extensos.

`@nodecfdi/base-converter` resuelve este problema operando directamente sobre secuencias de caracteres con aritmética de precisión arbitraria.

## Características principales

- **Precisión arbitraria**: Convierte números de cualquier longitud sin desbordamientos ni pérdida de dígitos.
- **Secuencias personalizadas**: Define tu propio alfabeto o diccionario de caracteres mediante [`BaseConverterSequence`](/packages/base-converter/api-reference/base-converter-sequence).
- **Soporte Base 36 integrado**: Incluye un método de fábrica listo para usar con el estándar alfanumérico (`0-9` y `A-Z`).
- **Multiplataforma (Isomórfico)**: Funciona sin dependencias externas tanto en **Node.js** como en **navegadores modernos**.
- **Tipado estricto**: Desarrollado íntegramente en TypeScript con definiciones de tipos incluidas.
