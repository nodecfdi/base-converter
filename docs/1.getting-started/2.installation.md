Puedes instalar `@nodecfdi/base-converter` utilizando tu gestor de paquetes favorito.

::steps

### Instalar el paquete

Ejecuta el comando correspondiente en la raíz de tu proyecto:

::code-group
```bash [npm]
npm install @nodecfdi/base-converter
```

```bash [pnpm]
pnpm add @nodecfdi/base-converter
```

```bash [yarn]
yarn add @nodecfdi/base-converter
```

```bash [bun]
bun add @nodecfdi/base-converter
```
::

### Importar y verificar la instalación

Importa la clase [`BaseConverter`](/packages/base-converter/api-reference/base-converter) y realiza una conversión de prueba para verificar que todo funcione correctamente:

```ts [index.ts]
import { BaseConverter } from '@nodecfdi/base-converter';

const converter = BaseConverter.createBase36();

// Convertir de hexadecimal (base 16) a binario (base 2)
const result = converter.convert('FFFF', 16, 2);

console.log(result); // "1111111111111111"
```

::

::note
Este paquete se distribuye como **ES Module (ESM)** para Node.js y bundlers modernos, e incluye además un bundle **IIFE** (`globalName: ncfdiBaseConverter`) para [uso directo en navegadores](/packages/base-converter/usage/browser-iife).
::
