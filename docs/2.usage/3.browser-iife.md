`@nodecfdi/base-converter` incluye una compilación en formato **IIFE** (*Immediately Invoked Function Expression*) lista para usarse directamente en el navegador mediante una etiqueta `<script>`, sin necesidad de un bundler.

El paquete expone todas sus exportaciones dentro de la variable global `ncfdiBaseConverter`.

## Cargar desde un CDN

Puedes incluir el archivo `dist/index.iife.js` desde un CDN como **unpkg** o **jsDelivr**:

::code-group
```html [unpkg]
<script src="https://unpkg.com/@nodecfdi/base-converter/dist/index.iife.js"></script>
```

```html [jsDelivr]
<script src="https://cdn.jsdelivr.net/npm/@nodecfdi/base-converter/dist/index.iife.js"></script>
```
::

## Ejemplo básico en HTML

Una vez cargado el script, puedes acceder a [`BaseConverter`](/packages/base-converter/api-reference/base-converter) y [`BaseConverterSequence`](/packages/base-converter/api-reference/base-converter-sequence) desde el objeto global `ncfdiBaseConverter`:

```html [index.html]
<!doctype html>
<html lang="es">
  <head>
    <meta charset="utf-8" />
    <title>Ejemplo con @nodecfdi/base-converter</title>
    <script src="https://unpkg.com/@nodecfdi/base-converter/dist/index.iife.js"></script>
  </head>
  <body>
    <script>
      const { BaseConverter, BaseConverterSequence } = ncfdiBaseConverter;

      // 1. Conversión usando Base 36 estándar
      const converter = BaseConverter.createBase36();
      const serialHex = '3330303031303030303030333030303233373038';
      const serialDec = converter.convert(serialHex, 16, 10);

      console.log('Decimal:', serialDec);
      // "292233162870206001759766198425879490508935868472"

      // 2. Conversión con secuencia personalizada
      const hexSequence = new BaseConverterSequence('0123456789ABCDEF');
      const hexConverter = new BaseConverter(hexSequence);

      console.log('Binario:', hexConverter.convert('FFFF', 16, 2));
      // "1111111111111111"
    </script>
  </body>
</html>
```
