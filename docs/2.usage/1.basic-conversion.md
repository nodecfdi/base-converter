La forma más sencilla de comenzar a convertir números entre bases estándar (desde base 2 hasta base 36) es utilizando el método estático `BaseConverter.createBase36()`.

Este método crea una instancia de [`BaseConverter`](/packages/base-converter/api-reference/base-converter) configurada con la secuencia alfanumérica estándar `0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ`.

## Conversiones entre bases comunes

El método `convert(input, frombase, tobase)` recibe el número como cadena de texto (`string`), la base de origen y la base de destino:

```ts [basic.ts]
import { BaseConverter } from '@nodecfdi/base-converter';

const converter = BaseConverter.createBase36();

// Hexadecimal (16) a Binario (2)
console.log(converter.convert('ffff', 16, 2));
// "1111111111111111"

// Decimal (10) a Hexadecimal (16)
console.log(converter.convert('255', 10, 16));
// "FF"

// Binario (2) a Decimal (10)
console.log(converter.convert('101010', 2, 10));
// "42"

// Base 36 a Decimal (10)
console.log(converter.convert('Z', 36, 10));
// "35"
```

::tip
La entrada `input` no distingue entre mayúsculas y minúsculas (`'ffff'` y `'FFFF'` producen el mismo resultado). El valor devuelto siempre utilizará los caracteres en mayúsculas definidos en la secuencia.
::

## Conversión de números largos (Certificados SAT)

El caso de uso principal de `@nodecfdi/base-converter` es convertir números que exceden el límite de precisión de 53 bits de `Number` en JavaScript (donde `parseInt` devuelve notación científica o redondea dígitos cuando el valor es $\ge 10^{21}$).

Por ejemplo, al convertir un número de serie hexadecimal de 40 caracteres a decimal:

```ts [long-numbers.ts]
import { BaseConverter } from '@nodecfdi/base-converter';

const converter = BaseConverter.createBase36();

const hexSerial = '3330303031303030303030333030303233373038';
const decimalSerial = converter.convert(hexSerial, 16, 10);

console.log(decimalSerial);
// "292233162870206001759766198425879490508935868472"
```

## Comportamiento con cadenas vacías y ceros

- Si `input` es una cadena vacía (`""`), se interpreta automáticamente como el primer carácter de la secuencia (equivalente a `0` en la secuencia estándar).
- Si `input` contiene múltiples ceros a la izquierda (por ejemplo `"0000000"`), el resultado se normaliza a un único carácter cero (`"0"`).

```ts [zeros.ts]
import { BaseConverter } from '@nodecfdi/base-converter';

const converter = BaseConverter.createBase36();

console.log(converter.convert('', 10, 2)); // "0"
console.log(converter.convert('0000000', 2, 16)); // "0"
```
