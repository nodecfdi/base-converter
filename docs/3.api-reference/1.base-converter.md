La clase `BaseConverter` ejecuta la conversión de cadenas numéricas entre distintas bases utilizando una secuencia definida por [`BaseConverterSequence`](/packages/base-converter/api-reference/base-converter-sequence).

## Importación

```ts
import { BaseConverter } from '@nodecfdi/base-converter';
```

## Constructor

### `new BaseConverter(sequence)`

Crea una nueva instancia de `BaseConverter` asociada a una secuencia de caracteres específica.

- **Parámetros:**
  - `sequence`: [`BaseConverterSequence`](/packages/base-converter/api-reference/base-converter-sequence) — Objeto de valor que contiene el diccionario de dígitos válidos.

```ts
const sequence = new BaseConverterSequence('0123456789ABCDEF');
const converter = new BaseConverter(sequence);
```

## Métodos estáticos

### `BaseConverter.createBase36()`

Método de fábrica que devuelve una instancia de `BaseConverter` preconfigurada con la secuencia alfanumérica estándar de 36 caracteres (`0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ`).

- **Retorna:** `BaseConverter`

```ts
const converter = BaseConverter.createBase36();
```

## Métodos de instancia

### `sequence()`

Devuelve la instancia de [`BaseConverterSequence`](/packages/base-converter/api-reference/base-converter-sequence) utilizada por el convertidor.

- **Retorna:** `BaseConverterSequence`

```ts
const currentSequence = converter.sequence();
console.log(currentSequence.value());
```

### `maximumBase()`

Devuelve el número entero de la base máxima soportada por el convertidor, que equivale a la longitud de la secuencia configurada.

- **Retorna:** `number`

```ts
const converter = BaseConverter.createBase36();
console.log(converter.maximumBase()); // 36
```

### `convert(input, frombase, tobase)`

Convierte una cadena numérica `input` expresada en la base `frombase` hacia su representación en la base `tobase`.

- **Parámetros:**
  - `input`: `string` — Cadena de texto con el número a convertir. Si es una cadena vacía (`""`), se toma como el primer carácter de la secuencia (`0`). Se procesa de forma insensible a mayúsculas y minúsculas.
  - `frombase`: `number` — Base numérica de entrada (se trunca a entero con `Math.floor`). Debe estar entre `2` y `maximumBase()`.
  - `tobase`: `number` — Base numérica de salida (se trunca a entero con `Math.floor`). Debe estar entre `2` y `maximumBase()`.
- **Retorna:** `string` — Representación del número en la base de destino.
- **Excepciones (`Error`):**
  - `'Invalid from base'`: Si `frombase` no es finito, es menor a `2` o mayor a `maximumBase()`.
  - `'Invalid to base'`: Si `tobase` no es finito, es menor a `2` o mayor a `maximumBase()`.
  - `'The number to convert contains invalid characters'`: Si `input` contiene algún carácter que no existe en la secuencia o cuyo índice es mayor o igual a `frombase`.

```ts
const converter = BaseConverter.createBase36();
const binary = converter.convert('FF', 16, 2); // "11111111"
```
